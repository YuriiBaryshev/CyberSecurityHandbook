### Додаткові команди для аналізу цілісності

#### git pull
Команда **`git pull`** використовується для отримання (fetch) змін з віддаленого репозиторію та їх автоматичного злиття (merge) з поточною локальною гілкою. Це важливий інструмент для підтримки цілісності копії, оскільки він забезпечує включення всіх останніх змін від команди.

#### git log
Команда **`git log`** показує всю історію комітів репозиторію, включаючи автора, дату та повідомлення коміту. Це дозволяє простежити, хто і коли вносив зміни, що є критичним для **захисту цілісності даних** та аудиту змін.
